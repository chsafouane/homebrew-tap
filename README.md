# Homebrew Tap for Privdo

Private, encrypted todo list with AES-256 encryption and PIN-protected vault.

## Install

```bash
brew tap chsafouane/tap
brew install --cask privdo
```

## Update

```bash
brew upgrade --cask privdo
```
